# HardwareHub SRS (Milestone context)

See the full Software Requirements Specification provided for the project vision.

This repository currently implements **Milestone 1** only:

- Spring Boot + Angular + PostgreSQL + Docker Compose + Flyway
- JWT authentication (login, logout, refresh, forgot/reset/change password)
- User management with role-based authorization

Later milestones (catalog, customers, inventory, sales, quotations, reports) are intentionally not implemented yet.
